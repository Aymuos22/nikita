# Dataset provenance

`sample/` contains synthetic records generated by `social_cli generate 12 data/sample` with fixed seed 15. It contains no real people, accounts or posts. The generator is implemented in `src/network.cpp`: a directed ring ensures reachability, up to three additional random relationships per user add variation, each user publishes one synthetic post in one of three topics, and interaction timestamps are monotonically increasing synthetic counters.

The sample records and generated datasets are dedicated to the public domain under CC0-1.0. No third-party dataset was downloaded. Generated scenario delays, costs, strengths and capacities are educational units and carry no measured real-world interpretation. Use `generate` for larger reproducible datasets; the benchmark runner also constructs an adversarial reverse-ordered chain and repeated-prefix text in memory.
